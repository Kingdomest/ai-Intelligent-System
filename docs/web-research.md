# Agent 网络资料搜索

## 公开新闻与事件

提问涉及近期公开新闻、事件、事故或争议时，Agent 会先通过 Google News RSS 检索文章标题、媒体、发布日期和链接，再依据这些证据回答。这条路径无需 API 密钥。默认的“请求批准”模式会先显示联网授权；批准后才发送搜索词。选择“完全访问权限”可直接执行。搜索失败或没有文章时，任务会停下并说明原因，不会凭模型记忆编造事件细节。

完成的回答上方显示“搜索到 N 个网页”，可以展开并打开文章来源链接。Google News RSS 提供的是新闻文章入口链接；搜索证据只有标题和日期，不等于已经读取文章全文。回答应明确资料的时间和核实范围。

## 一般技术资料与知识检索

规划任务、编写源码文件或生成临时工具时，Agent 可选择检索陌生或可能变化的公开知识。这部分使用 Brave Search API，需要在 `.env` 中设置 `BRAVE_SEARCH_API_KEY=...` 并重启服务。当前的后台资料预检仅在“帮我批准”或“完全访问权限”模式运行；“请求批准”模式不会在后台静默调用搜索服务。

搜索词最多两个，且会过滤常见路径、URL、邮箱与密钥格式。附件正文和源码文件不会直接发送给搜索服务。搜索结果作为不可信资料处理，不作为指令执行。搜索服务不可用时，模型会收到不可用标记。

通过工具实际取得的公开网络 URL 也会进入来源列表。失败或取消的任务不展示来源卡片；链接会过滤不安全协议和常见密钥参数。
