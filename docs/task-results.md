# 任务结果模板

所有工具任务的最终结果使用同一个模板，适用于聊天消息、任务 API 和会话历史。

```text
执行状态：任务已完成 / 任务未完成 / 任务已阻塞 / 任务已停止

结果摘要：
直接回答用户问题的一两句话。

关键结果：
- 字段名称：具体结果
- 字段名称：具体结果

说明：
- 覆盖范围、跳过项目、不完整数据等实际限制。

后续操作：
- 仍需要用户处理的事项。
```

“执行状态”和“结果摘要”始终显示；其他区块在有内容时显示。执行状态由运行时确定。普通聊天和演示文稿正文保留原有格式。

回答模型输出 `summary`、`details`（`label` / `value` 数组）、`warnings`、`nextSteps` 四个字段；字段结构通过 Zod 校验后由程序渲染，避免模型各自生成不同版式。

进程的 JSON 标准输出会先解析成数据，再交给回答模型生成结论。聊天消息不直接展示 `exitCode`、`stdout`、`stderr` 或转义后的原始 JSON。原始执行输出仍保留在操作记录中，用于测试、评估和排查问题。命令执行完成后只重新生成回答，不重复运行命令。

文件大小类任务应给出扫描范围、完整路径、可读大小和精确字节数。跳过项目只按实际证据说明，不推断跳过原因，也不把可访问范围的结果说成完整扫描结果。
